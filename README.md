# BAZARINO — راهنمای کامل راه‌اندازی

این سایت یک فروشگاه آنلاین کامل با پنل مدیریت پنهان است که روی **گیت‌هاب پیجز** هاست می‌شود و دیتابیسش **Firebase** (رایگان) است. با این ترکیب:
- سایت هم روی گوشی هم کامپیوتر درست و حرفه‌ای دیده می‌شود.
- هر لباسی که از پنل مدیریت (از هر دستگاهی) اضافه کنی، همان لحظه برای همه بازدیدکننده‌ها نمایش داده می‌شود.
- آمار بازدید و تعداد کاربران واقعی ذخیره می‌شود.
- عکس‌ها در Firebase Storage ذخیره می‌شوند و هیچ‌وقت پاک/گم نمی‌شوند.

---

## مرحله ۱ — ساخت پروژه Firebase (۵ دقیقه، رایگان)

1. وارد [console.firebase.google.com](https://console.firebase.google.com) شو و با جیمیلت وارد شو.
2. روی **Add project** بزن، اسمش رو بذار مثلا `bazarino-shop` و پروژه رو بساز.
3. از منوی سمت چپ روی آیکون `</>` (Web) بزن تا یک اپ وب بسازی. اسمی براش بذار و Register کن.
4. یک کد شبیه این بهت نشون داده می‌شه:
```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```
این مقادیر را کپی کن و در فایل `js/firebase-config.js` به جای مقادیر فعلی جایگزین کن.

5. از منوی سمت چپ:
   - **Build → Firestore Database → Create database** را بزن (در حالت production mode).
   - **Build → Authentication → Get started** را بزن و روش **Email/Password** را فعال کن.
   - در تب **Users**، یک کاربر ادمین با ایمیل و رمز دلخواه خودت بساز (همین ایمیل/رمز را برای ورود به پنل مدیریت استفاده می‌کنی).
   - **Build → Storage → Get started** را بزن (برای ذخیره عکس‌ها).

## مرحله ۲ — تنظیم قوانین امنیتی (خیلی مهم)

### Firestore Rules
در بخش Firestore → تب **Rules**، این را جایگزین کن:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```
یعنی: همه می‌توانند محصولات را ببینند، ولی فقط کسی که وارد پنل مدیریت شده (لاگین کرده) می‌تواند چیزی اضافه/تغییر بدهد.

### Storage Rules
در بخش Storage → تب **Rules**:
```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

## مرحله ۳ — آپلود لوگو

عکس لوگویی که فرستادی را با نام دقیق `logo.png` داخل پوشه `assets/` بگذار (جایگزین فایل فعلی که نمونه است).

## مرحله ۴ — آپلود روی گیت‌هاب و فعال‌سازی گیت‌هاب‌پیجز

1. یک ریپازیتوری جدید در گیت‌هاب بساز، مثلا به نام `bazarino`.
2. همه فایل‌های این پوشه (`index.html`, `product.html`, `panel-ctrl-7f3k.html`, پوشه‌های `css` و `js` و `assets`) را در آن ریپازیتوری آپلود کن.
3. برو به تنظیمات ریپازیتوری → **Pages** → از قسمت Source شاخه `main` و پوشه `/root` را انتخاب کن و Save بزن.
4. بعد از چند دقیقه، سایتت روی آدرسی شبیه `https://username.github.io/bazarino/` بالا می‌آید.

## مرحله ۵ — ورود به پنل مدیریت (پنهان)

پنل مدیریت در هیچ‌جای سایت لینک نشده و در منو نیست. آدرسش این است:
```
https://username.github.io/bazarino/panel-ctrl-7f3k.html
```
این لینک را فقط برای خودت نگه‌دار. برای امنیت بیشتر، **پیشنهاد می‌کنم اسم این فایل را عوض کنی** (مثلا به یک اسم عجیب‌تر که فقط خودت می‌دونی) و همین اسم جدید را در آدرس بالا استفاده کنی. حتی اگر کسی این آدرس را حدس بزند، بدون ایمیل و رمزی که در مرحله ۱ ساختی نمی‌تواند وارد شود چون Firestore هم قفل است.

برای ورود، همان ایمیل و رمزی که در Authentication ساختی را وارد کن.

## نحوه کار پنل مدیریت

- **محصولات**: شاخه را انتخاب می‌کنی، نام/قیمت/موجودی را می‌نویسی، رنگ و سایز را تایپ و Enter می‌زنی (می‌تونی چندتا اضافه کنی)، عکس‌ها را آپلود می‌کنی (چند عکس همزمان) و نوع نمایش گالری (اسلایدی یا ریلی اسکرولی) را انتخاب می‌کنی، بعد «ثبت محصول» را می‌زنی — همان لحظه در صفحه اصلی زیر همان شاخه‌ای که انتخاب کردی ظاهر می‌شود.
- **دسته‌بندی‌ها**: هر چقدر بخواهی شاخه (مجلسی، پالتو، مانتو، ...) اضافه/حذف کن. همین‌ها در منوی کرکره‌ای سمت راست سایت نمایش داده می‌شوند.
- **تبلیغات**: برای هر کدام از ۳ جای تبلیغات، عکس بنر (اندازه پیشنهادی ۳۰۰×۴۰۰ پیکسل) و لینک مقصد را تنظیم کن.
- **مطالب جدید**: اسلایدهایی که در باکس «مطالب جدید» بالای ستون چپ نمایش داده می‌شوند.
- **تماس با ما**: متنی که با کلیک روی دکمه «تماس با ما» در صفحه اصلی باز می‌شود (شماره، آیدی و...) را همین‌جا بنویس.
- **آمار**: تعداد بازدید کل و تعداد کاربران یکتا (کسانی که برای اولین‌بار سایت را باز کرده‌اند).

## سفارش و خرید

وقتی مشتری رنگ/سایز را انتخاب کند و روی «خرید محصول» بزند، سه گزینه نمایش داده می‌شود: تلگرام، روبیکا، بله. با کلیک روی هرکدام، چت مستقیم با آیدی‌های زیر باز می‌شود:
- تلگرام: `pbazarinoshop1` (با متن آماده شامل نام محصول، رنگ و سایز)
- روبیکا: `shopbazarino`
- بله: `shopbazarino`

اگر این آیدی‌ها عوض شد، کافیست در فایل `js/firebase-config.js` بخش `SOCIAL_LINKS` را ویرایش کنی.

## نکات مهم

- صفحه‌بندی محصولات خودکار است: هر صفحه ۱۲ محصول نشان می‌دهد و اگر بیشتر شد، شماره صفحه‌ها پایین صفحه ظاهر می‌شوند.
- فونت سایت «وزیرمتن» است که زیبا و مخصوص فارسی است.
- رنگ‌بندی طلایی/مشکی هدر، هماهنگ با لوگوی ارسالی توست.
- اگر چیزی نیاز به تغییر داشت (رنگ، چیدمان، فیلد جدید) بگو تا برات اصلاح کنم.
